# Appendix — concept sets per phenotype

One CSV per phenotype: every concept a `pheno=` target selects, with how it entered the set, who judged it, and whether the corpus writes it. Generated by `analysis/export_concept_appendix.py`.

**Identifiers only.** UMLS preferred terms are licensed content and are not redistributed here; a companion export carrying them is written to `data/appendix/concepts_with_terms/` (gitignored) for a reader who holds a licence. Resolve any CUI against your own release.

| column | meaning |
|---|---|
| `facet` | disorder closure, MED-RT medication, declared finding, LLM-proposed, or evidence closure |
| `provenance` | how it was reached — seed, closure, lift, identity (RxNorm brand/product of a kept ingredient), declared, grounded |
| `vetted` | `keep` = explicitly judged clinically appropriate; `auto` = asserted by a curated source and not model-reviewed |
| `category` | the shipped exclusive partition (one category per concept) |
| `in_corpus` / `corpus_mentions` | does any of the 1,388 notes write it, and how often |
| `in_sample` / `sample_mentions` | the same over the 500 evaluated notes |

Rows are sorted by corpus frequency, so the concepts that carry the evidence appear first. `index.csv` summarises the panel.
